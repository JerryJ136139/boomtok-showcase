# Screenshot guidelines

Only synthetic demo data may be used in public product images.

Before adding a screenshot, confirm that it contains none of the following:

- Real names, usernames, email addresses, account identifiers, or profile photos
- Private messages, notifications, moderation reports, or administrative records
- Storage URLs, database identifiers, deployment IDs, or test credentials
- Team-only implementation notes or unreleased product information

Recommended public images: vertical feed, upload workflow, synthetic private conversation, and support center.
