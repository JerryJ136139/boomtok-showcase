# Screenshot guidelines

Only synthetic demo data may be used in public product images.

Current public walkthrough images:

- `01-video-feed.png` — synthetic short-video feed
- `02-messaging.png` — fabricated one-to-one conversation and video share
- `03-discover.png` — anonymous discovery hub
- `04-super-topics.png` — anonymous fan-community directory
- `05-authentication.png` — empty authentication form

Before adding a screenshot, confirm that it contains none of the following:

- Real user names, usernames, email addresses, account identifiers, or profile photos
- Private messages, notifications, moderation reports, or administrative records
- Storage URLs, database identifiers, deployment IDs, or test credentials
- Team-only implementation notes or unreleased product information

Public conversation images must use clearly fabricated names, account identifiers, avatars, and message text. Public-figure or community names may appear only where they are already part of anonymous product discovery content.
